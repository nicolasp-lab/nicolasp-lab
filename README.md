### 📂 Projetos

#### [Scheduler — Sistema de Agendamento](https://github.com/nicolasp-lab/scheduler)

Aplicação full-stack para gerenciamento de serviços e agendamentos, com interface pública para clientes e painel administrativo.

- Backend estruturado com Clean Architecture.
- Autenticação JWT com cookies HttpOnly.
- Controle de disponibilidade e gerenciamento de agendamentos.
- Dashboard administrativo e gestão de serviços.

**Stack:** TypeScript, Node.js, Express, Next.js, PostgreSQL e Prisma.

[Repositório](https://github.com/nicolasp-lab/scheduler) · [Demo](https://scheduler-occy.vercel.app/)

#### [Inova Caraguá — Sistema de Gestão](https://github.com/andreluizdasilvaa/Inova-Caragua)

Projeto desenvolvido em equipe durante um hackathon acadêmico do IFSP Caraguatatuba, com **2º lugar na competição**.

Sistema de gestão de inventário e ocorrências, com controle de acesso por diferentes perfis de usuários e acompanhamento de solicitações.

- Gerenciamento de inventário e ocorrências.
- Autenticação e controle de acesso.
- Fluxo de triagem, aprovação e acompanhamento.
- Integração com banco de dados PostgreSQL.

**Stack:** TypeScript, Next.js, NextAuth.js, PostgreSQL, Prisma e Tailwind CSS.

[Repositório](https://github.com/andreluizdasilvaa/Inova-Caragua) · [Demo](https://inova-caragua.vercel.app/)
